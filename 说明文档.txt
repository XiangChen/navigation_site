================================================================================
                    AI NEXUS 导航站 — 项目使用说明
================================================================================

一、项目简介
--------------------------------------------------------------------------------
本项目是一个 AI 工具导航网站（品牌名 AI NEXUS），收录了 1717 个 AI 工具 +
51 个 AI API，按 15 个大类分类展示。点击工具卡片可进入详情页查看介绍，
再通过 "Official Website" 按钮跳转到对应的官方网站。

技术栈：
  - Vue 3 + Vue Router 4（前端框架 & 路由）
  - Vite 5（构建工具 & 开发服务器）
  - Tailwind CSS 3（UI 样式框架）
  - PostCSS + Autoprefixer（CSS 预处理）

二、解压后如何运行（详细步骤）
================================================================================

【前置条件】
请确认电脑上已安装以下软件：
  1. Node.js（版本 >= 18，建议 18.x LTS）
     - 下载地址：https://nodejs.org/
     - 验证安装：打开命令行，输入 "node -v" 和 "npm -v"
       能看到版本号（如 v18.20.x、10.x.x）即为安装成功。

【步骤一：进入项目目录】
  1. 把压缩包解压到任意位置（例如 D:\navigation_site）
  2. 打开命令行（Windows: Win+R 输入 cmd 或 PowerShell）
  3. 进入解压后的目录：
       cd D:\navigation_site

【步骤二：安装依赖】
  在项目目录下执行：
       npm install
     或 npm i
  说明：
  - 第一次执行会下载 node_modules（约几百 MB），需要联网，请耐心等待。
  - 如果下载速度慢，可切换到淘宝镜像：
       npm config set registry https://registry.npmmirror.com
    再重新执行 npm install。
  - 依赖安装完成后，会生成 / 或更新 node_modules 文件夹。

【步骤三：启动开发服务器（预览网页）】
  执行：
       npm run dev
  看到类似如下输出就说明启动成功：
       VITE v5.x.x  ready in XXX ms
       -> Local:   http://localhost:5180/
  默认会自动打开浏览器，无需手动输入地址。
  （本项目在 vite.config.js 里固定了端口 5180，不自动退让冲突；
   如果 5180 被占用，会直接报错，手动改 --port 即可。）

  停止开发服务器：在命令行按 Ctrl + C。

【步骤四（可选）：打包成生产环境静态文件】
  执行：
       npm run build
  打包完成后会生成 dist/ 目录，里面就是纯静态的 HTML/CSS/JS/图片文件。
  可把 dist/ 整个放到 Nginx、Apache 或任意静态文件服务器上部署。

【步骤五（可选）：本地预览打包结果】
  在 build 之后执行：
       npm run preview
  默认会在 http://localhost:4173/ 启动预览，用于验证生产构建是否正常。

四、常见问题 FAQ
================================================================================

Q1: npm install 卡住了 / 报错 "ETIMEDOUT"？
A: 是网络问题，切换到淘宝镜像：
       npm config set registry https://registry.npmmirror.com
    再重新 npm install。

Q2: 打开浏览器显示白屏？
A: 通常是依赖未安装完整，先 npm install；或者看浏览器 F12 控制台报错。

Q3: 工具详情页的 Official Website 点了跳 Google 搜索？
A: 说明该工具在 tool_urls.js 里暂无官网映射，可以去
    src/data/tool_urls.js 里添加一行映射（格式见文件内部注释）。

Q4: 想新增/修改工具数据？
A: 改 src/data/tools.js（工具详情）或 src/data/tool_urls.js（官网 URL）。
   或准备好 Excel 后，运行 generate_data.py 重新生成这两个数据文件。

Q5: 要部署到服务器怎么操作？
A: 执行 npm run build 得到 dist/ 目录，把 dist 下所有文件上传到
   服务器静态根目录即可（例如 Nginx 的 /usr/share/nginx/html）。

Q6: 可以删除哪些文件减少压缩包体积？
A: 可安全删除以下文件/目录（运行时不依赖，仅开发/备份用途）：
   - aixzd/ 及 aixzd(1).zip（仅做数据溯源，运行时读的是 src/data/*.js）
   - generate_data.py（仅生成数据用）
   - node_modules/（运行前 npm install 会自动重建，但要留 package.json）
   - dist/（如果之前 build 过）
   - .git/ 和 .gitignore（如无需版本管理）
